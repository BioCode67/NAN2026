# 아트 생성 규격

캐릭터 스프라이트 시트와 아이템 아이콘을 AI로 생성할 때 쓰는 지시문이다.
**캐릭터 이름과 외형 설명만 바꿔서** 그대로 붙여넣으면 된다.

---

## 1. 캐릭터 스프라이트 시트

### 아트 디렉션 — 먼저 읽을 것

1차 생성물이 **캐리커처처럼 나와 게임 캐릭터로 안 보이는 문제**가 있었다.
원인은 비율이다. "SD 스타일"이라고만 쓰면 생성기가 거의 실사 비율(6~7등신)로
그린다. 게임 캐릭터는 **실루엣만 봐도 누군지 구분되어야** 한다.

반드시 명시할 것:

- **2~2.5등신**. 머리가 몸통+다리를 합친 것과 비슷하게 크다
- **과장된 표정** — 눈을 부릅뜨거나 이빨을 드러내는 등 감정이 극단적
- **굵고 진한 검은 외곽선** — 배경에서 캐릭터가 튀어나와 보여야 한다
- **채도 높은 색** — 어두운 배경 위에 올라간다
- **액션 프레임은 만화적으로 과장** — 팔다리가 늘어나고 스피드선이 붙는다
- **상징 소품을 크게** — 그 인물이라고 바로 알아볼 수 있게

### 지시문 (복붙)

```
2D 대전 격투 게임용 스프라이트 시트를 만들어줘.

[캐릭터] <이름>을 극단적으로 과장한 SD 도트 캐릭터.
<외형 설명: 옷 색, 머리 모양, 안경/수염 등>
<엽기 포인트: 아래 캐릭터별 표 참고>

[아트 스타일 — 중요]
- 2~2.5등신. 머리가 몸 전체만큼 크게. 실사 비율 금지
- 표정을 극단적으로 과장할 것 (부릅뜬 눈, 드러낸 이빨, 광기)
- 굵고 진한 검은 외곽선. 어두운 배경에서 실루엣이 확실히 분리될 것
- 채도 높고 대비 강한 색
- 액션 프레임은 만화처럼 과장 (늘어난 팔다리, 스피드선, 임팩트)
- 귀엽고 얌전한 캐리커처가 아니라, 시끄럽고 우스꽝스러운 게임 캐릭터

[필수 규칙]
- 배경: 완전 투명 PNG. 체크무늬를 그려 넣지 말 것.
  (투명이 안 되면 순수 마젠타 #FF00FF 단색으로. 캐릭터에는 이 색을 쓰지 말 것)
- 글자 금지: 프레임 이름/라벨/워터마크를 이미지에 넣지 말 것
- 격자 배치, 프레임 사이 간격은 캐릭터 폭의 20% 이상 확보
- 모든 프레임에서 캐릭터가 오른쪽을 향할 것
- 모든 프레임 크기·비율 동일, 발끝을 같은 높이에 맞출 것
- 이펙트(기술 효과)가 옆 프레임을 침범하지 않게 할 것
- 오른손은 물건을 쥘 수 있게 비워두고, 손목 높이를 프레임마다
  크게 흔들리지 않게 유지할 것 (아이템 장착 대비)

[프레임 15개, 이 순서로]
1행: IDLE, WALK, RUN-A, RUN-B, JUMP
2행: ATTACK_J(약공격), ATTACK_K(강공격), SKILL_L(스킬 시전), SKILL_L2(스킬 이펙트)
3행: HIT(피격), KNOCKBACK(날아감), GUARD(방어), DASH(대시), WIN(승리), LOSE(패배)
```

### 캐릭터별 엽기 포인트

위 지시문의 `<엽기 포인트>` 자리에 그대로 넣는다.

| 캐릭터 | 넣을 문장 |
|---|---|
| **빌 게이츠맨** | 안경 렌즈에 파란 블루스크린이 번쩍이고, 스웨터 주머니에서 지폐가 삐져나온다. 세상을 다 사버린 듯한 능글맞은 미소. 손에는 푸른 에너지구. |
| **스티브 잡스맨** | 검은 터틀넥에 몸 뒤로 후광이 비친다. 눈은 광신도처럼 번뜩이고, 한 손을 치켜든 프레젠테이션 자세. 배경에 무지개 사과 잔상. |
| **일론 머스크맨** | 등에 작은 로켓을 매달고 불꽃을 뿜는다. 두 눈이 도지코인 모양. 입은 항상 씩 웃고 있고 머리가 바람에 뒤로 날린다. |
| **리누스 토발즈맨** | 펭귄(턱스) 모자를 쓰고 있고, 잔뜩 인상 쓴 채 이빨을 드러낸다. 주변에 초록색 터미널 글자가 떠다닌다. |
| **패니 와이즈맨** | 완전한 개구리 얼굴. 얼굴을 가로지르는 거대한 입, 툭 튀어나온 흰 눈알. 손에는 로켓 모양 주식 차트. |

### 왜 이 항목들인가

실제로 겪은 문제에서 나온 규칙이다.

| 규칙 | 안 지켰을 때 |
|---|---|
| 투명 배경 | 체크무늬가 픽셀로 칠해져 오면 배경 분리에 시간이 든다. 반투명 이펙트는 복구 불가 |
| 라벨 금지 | `IDLE` 같은 글자가 게임 화면에 함께 렌더된다 |
| 프레임 간격 | 인접 프레임이 한 덩어리로 붙어 잘못 잘린다 |
| 방향 통일 | 캐릭터마다 좌우 반전이 어긋난다 (`facesLeft` 수동 지정 필요) |
| 발끝 정렬 | 애니메이션 중 캐릭터가 위아래로 튄다 |
| 오른손 비우기 | 나중에 아이템을 손에 쥐게 하려면 시트를 다시 뽑아야 한다 |

### SKILL_L2 는 두 가지로 쓸 수 있다

- **캐릭터 + 이펙트** (스티브 잡스): 2프레임 애니메이션으로 연속 재생
- **이펙트 단독** (빌 게이츠): 투사체 스프라이트로 사용
  → `characters.ts`의 `skill.projectile.frame` 에 지정

원거리 스킬 캐릭터는 **이펙트만 단독으로** 그려달라고 하는 편이 활용도가 높다.

## 2. 변환

```bash
node tools/process-sheet.mjs art-source/<이름>_sheet.png public/sprites/<key>.png
```

세 가지 입력을 모두 처리한다.

- 투명 PNG → 알파 그대로 사용 (가장 깨끗)
- 단색 배경(마젠타 등) → 그 색 제거
- 체크무늬 시안 → 두 톤 제거

출력 로그에 프레임 순서가 찍힌다. 그 순서대로
`src/config/spriteSheets.ts` 의 `poses` 에 매핑하면 끝이다.

해상도를 바꾸려면 `MAX_FRAME_H=320 node tools/process-sheet.mjs ...`

## 3. 아이템 아이콘

아이템은 **캐릭터 몸에 그리지 않는다.** 캐릭터 주변 오라 + 머리 위 아이콘으로
표현하므로, 아이콘 하나만 있으면 된다.

```
게임 UI용 아이템 아이콘을 만들어줘.

[아이템] <이름> — <설명>
[규칙]
- 완전 투명 PNG, 정사각형
- 64x64 픽셀 아트 스타일
- 배경/테두리 없이 오브젝트만
- 어두운 배경 위에 올라가므로 밝고 채도 높게
```

현재는 이모지로 임시 대체하고 있다 (`src/config/items.ts` 의 `icon`).
아이콘 이미지를 넣을 준비가 되면 `iconKey` 로 바꾸면 된다.

## 4. 라이선스 기록 (대회 제출 필수)

AI로 생성한 에셋은 **④AI 활용 기술 문서**에 도구명과 생성 방식을 적어야 한다.
원본 시안은 `art-source/` 에 그대로 보관 중이므로 출처 추적이 가능하다.

- 캐릭터 시트: <생성 도구명> 으로 생성 → `tools/process-sheet.mjs` 로 전처리
- 사운드: 외부 음원 없음. Web Audio API 실시간 합성 (`src/systems/SoundSystem.ts`)
- 시트가 없는 캐릭터: Phaser 도형으로 코드 드로잉 (`src/characters/CharacterArt.ts`)
