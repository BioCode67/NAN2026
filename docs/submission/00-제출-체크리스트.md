## ⑤ 팀원 역할 기술서 — **2인 이상 팀만**

혼자 참가라면 **제출하지 않는다.**

팀이라면:

1. `_04-팀원역할-템플릿.html` 을 열어 내용을 채운다
2. 파일 이름 맨 앞의 밑줄(`_`)을 뗀다 → `04-팀원역할.html`
   (밑줄이 붙어 있으면 `npm run docs` 가 건너뛴다 — 안 채운 템플릿이
   그대로 PDF가 되는 것을 막기 위한 장치다)
3. `npm run docs`

| 회귀 검사 | `npm test` (타입·해석기·시트·봇·밸런스) · `npm run smoke` (브라우저 전 구간) · `npm run smoke:online` (창 여러 개로 온라인) · `npm run art:check` (받아 놓은 그림 점검) |

### 남은 아트

| 자리 | 파일 | 상태 |
|---|---|---|
| 옥상 헬리패드 | `public/bg/stage_storm.png` | ⬜ 아직 없음 |
| 용암 지대 | `public/bg/stage_lava.png` | ⬜ 아직 없음 |
| 캐릭터 시트 | `art-source/<id>/` | 20명 중 **5명** 완료 |

그림을 넣는 방법은 파일을 그 자리에 두고 아래 한 줄이면 된다.

```bash
npm run art:check --fix    # 시트 합치기 + WebP 변환 + 점검표(art-source/check.html)
```
