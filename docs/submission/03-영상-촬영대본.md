> 30~60초 · YouTube 업로드 · **실제 플레이 장면 중심** (AI 합성·도용 금지)
> 목표 길이 **55초**. 편집 없이 한 번에 찍어도 되도록 순서를 짜 두었다.

---

## 0. 찍기 전에 (5분)

```bash
npm run build && npm run preview    # 배포본과 같은 상태로 확인
```

또는 그냥 <https://biocode67.github.io/NAN2026/> 를 연다.

| 항목 | 설정 |
|---|---|
| 녹화 | OBS Studio · 1920×1080 · 60fps |
| 브라우저 | **F11 전체화면** (주소창·북마크가 보이면 안 된다) |
| 소리 | **음소거 해제** — 타격음·BGM이 이 게임의 절반이다 |
| 캐릭터 | **빌 게이츠맨** (1번). 지분 게이지가 눈에 보여 설명 없이 읽힌다 |
| 미리 | 한 판 연습해서 프롬프트 오브 등장 타이밍(개시 13초 뒤)을 익힌다 |

**주의** — 오브는 개시 **13초** 뒤에 처음 뜨고, 이후 26초 간격이다.
영상의 중심이 오브이므로, 그 전 구간을 12초 안에 채운다는 생각으로 찍는다.

## 1. 샷 리스트 (55초)

### ① 0:00 – 0:04 · 타이틀 → 캐릭터 선택 (4초)

- 타이틀 화면에서 바로 `Enter`
- 선택 화면에서 `D`를 **천천히 두세 번** 눌러 다섯 캐릭터를 훑는다
  → 카드마다 고유 규칙 설명이 바뀌는 것이 보인다
- 다시 빌 게이츠맨으로 돌아와 `Enter`

> **보여주는 것**: 다섯 명이 서로 다른 캐릭터라는 것

### ② 0:04 – 0:12 · 전투 개시 · 연속기 (8초)

- `FIGHT!` 직후 가까운 적에게 붙는다
- `J J J` — 잽 → 더블 클릭 → **강제 종료**(크게 띄운다)
- 띄운 적을 따라 `Space` 점프 → 공중 `K`
- 착지 후 `K K` — 독점 킥 → **인수 합병**(멀리 날린다)

> **보여주는 것**: 타격감 · 연속기 · 주가가 **오르는** 게이지
> 상대 주가가 내려가는 동시에 내 주가가 올라가는 장면이 잡혀야 한다

### ③ 0:12 – 0:18 · 커맨드 무브 (6초)

- `W`+`K` — Ctrl+Alt+Del (솟구치며 띄운다)
- `S`+`K` — 반독점 소송 (좌우 동시 타격)
- 공중에서 `S`+`K` — 강제 재부팅 (내리꽂기)

> **보여주는 것**: 같은 버튼이라도 방향에 따라 다른 기술이 나간다

### ④ 0:18 – 0:34 · **프롬프트 오브 — 핵심 장면** (16초)

가장 중요한 구간이다. 여기가 흐리면 영상 전체가 실패한다.

1. 오브가 뜨면 **다른 적을 무시하고** 오브를 친다 (`J` 연타)
2. 오브가 깨지는 순간 → 화면이 멈추고 입력창이 뜬다
3. 입력창에 **천천히, 또박또박** 친다:

   ```
   여기를 달로 만들어줘
   ```

4. `Enter` → **중력이 절반이 되고 배경이 달 표면으로 갈린다**
5. 저중력 상태로 크게 점프하며 공중 공격을 두어 번 넣는다

> **보여주는 것**: 이 게임의 정체성. 문장 하나가 판을 바꾼다
> **팁**: 입력을 너무 빨리 치지 말 것. 심사자가 글자를 읽을 시간이 필요하다

### ⑤ 0:34 – 0:44 · 두 번째 오브 — 규칙이 바뀐다 (10초)

- 두 번째 오브를 깨고 이번엔 **룰**을 부른다:

  ```
  리듬으로 승부하자
  ```

- 상단에 박자 게이지가 뜬다
- 박자에 맞춰 때려 **`PERFECT!` 2배** 판정을 최소 한 번 띄운다

> **보여주는 것**: 아이템이 아니라 **승부 규칙 자체**가 바뀐다는 것
> AI가 오브를 깨서 봇이 문장을 외치는 장면이 잡히면 그것도 좋다

### ⑥ 0:44 – 0:52 · 마무리 · 상장폐지 (8초)

- 스킬 `L` — 블루스크린 (지분을 모아 뒀다면 더 좋다)
- 마지막 적을 `K K`로 장외로 날려 **상장폐지** 연출을 띄운다

> **보여주는 것**: 스킬 연출 · KO

### ⑦ 0:52 – 0:55 · 결과 화면 (3초)

- 승리 화면을 3초 유지하고 끝낸다

## 4. 자주 어긋나는 것

| 증상 | 대응 |
|---|---|
| 오브가 안 뜬다 | 개시 13초 뒤 첫 등장. 그 전에 죽으면 `R`로 다시 |
| 3AI에게 둘러싸여 금방 죽는다 | 개시 직후 한쪽 끝으로 이동해 1:1 구도를 만든다 |
| 입력창이 너무 빨리 지나간다 | 문장을 다 친 뒤 1초 쉬고 `Enter` |
| 소리가 안 들어갔다 | OBS에서 **브라우저 탭 오디오**가 잡혔는지 확인 |
| 60초를 넘겼다 | ③ 커맨드 무브 구간(6초)을 통째로 뺀다. ④는 절대 줄이지 않는다 |
