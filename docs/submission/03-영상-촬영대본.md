# 제출물 ② 플레이 영상 — 촬영 대본

> 30~60초 · YouTube 업로드 · **실제 플레이 장면 중심** (AI 합성·도용 금지)
> 목표 길이 **58초**. 편집 없이 한 번에 찍어도 되도록 순서를 짜 두었다.
> 마지막 온라인 구간만 창을 두 개 띄우므로, 그 부분만 따로 찍어 이어 붙여도 된다.

---

## 0. 찍기 전에 (5분)

```bash
npm run build && npm run preview    # 배포본과 같은 상태로 확인
```

또는 그냥 <https://biocode67.github.io/NAN2026/> 를 연다.

| 항목 | 설정 |
|---|---|
| 녹화 | OBS Studio · 1920×1080 · 60fps |
| 브라우저 | **F11 전체화면** (주소창·북마크가 보이면 안 된다) |
| 소리 | **음소거 해제** — 타격음·BGM이 이 게임의 절반이다 |
| 캐릭터 | **빌 게이츠맨** (1번). 지분 게이지가 눈에 보여 설명 없이 읽힌다 |
| 미리 | 한 판 연습해서 프롬프트 오브 등장 타이밍(개시 13초 뒤)을 익힌다 |

**주의** — 오브는 개시 **13초** 뒤에 처음 뜨고, 이후 26초 간격이다.
영상의 중심이 오브이므로, 그 전 구간을 12초 안에 채운다는 생각으로 찍는다.

**온라인 구간(⑧)은 창을 두 개 띄워야 하므로 미리 준비해 둔다.**
같은 주소를 새 **창**으로 두 개 열어 좌우로 나란히 놓으면 된다 —
탭 두 개로 열면 뒤에 있는 쪽이 멈춰서 안 된다.

## 1. 샷 리스트 (55초)

### ① 0:00 – 0:03 · 타이틀 → 캐릭터 선택 (3초)

- 타이틀 화면에서 바로 `Enter`
- 선택 화면에서 `D`를 **천천히 대여섯 번** 눌러 로스터를 훑는다 (20명이 10×2로 늘어서 있다)
  → 카드마다 고유 규칙 설명이 바뀌는 것이 보인다
- 다시 빌 게이츠맨으로 돌아와 `Enter`

> **보여주는 것**: 스무 명이 각자 다른 캐릭터라는 것

### ② 0:03 – 0:11 · 전투 개시 · 연속기 (8초)

- `FIGHT!` 직후 가까운 적에게 붙는다
- `J J J` — 잽 → 더블 클릭 → **강제 종료**(크게 띄운다)
- 띄운 적을 따라 `Space` 점프 → 공중 `K`
- 착지 후 `K K` — 독점 킥 → **인수 합병**(멀리 날린다)

> **보여주는 것**: 타격감 · 연속기 · 주가가 **오르는** 게이지
> 상대 주가가 내려가는 동시에 내 주가가 올라가는 장면이 잡혀야 한다

### ③ 0:11 – 0:18 · 커맨드 무브 · 공격/가드/잡기 (7초)

- `W`+`K` — Ctrl+Alt+Del (솟구치며 띄운다)
- `S`+`K` — 반독점 소송 (좌우 동시 타격)
- **`K`를 꾹 눌러 차지** — 몸을 떨며 모으다 놓는다. 기술 이름에 `(풀차지)`가 붙는다
- 봇이 `S`로 막고 서 있을 때 **`U` 잡기 → `K` 던지기**

> **보여주는 것**: 같은 버튼이라도 방향에 따라 다른 기술이 나간다는 것,
> 그리고 **공격은 가드에 막히고 가드는 잡기에 뚫린다**는 삼각형.
> 차지와 잡기가 한 번씩만 나가도 "버튼을 세 개 쓰는 게임이 아니다"가 전달된다

### ④ 0:18 – 0:34 · **프롬프트 오브 — 핵심 장면** (16초)

가장 중요한 구간이다. 여기가 흐리면 영상 전체가 실패한다.

1. 오브가 뜨면 **다른 적을 무시하고** 오브를 친다 (`J` 연타)
2. 오브가 깨지는 순간 → 화면이 멈추고 입력창이 뜬다
3. 입력창에 **천천히, 또박또박** 친다:

   ```
   여기를 달로 만들어줘
   ```

4. `Enter` → **중력이 절반이 되고 배경이 달 표면으로 갈린다**
5. 저중력 상태로 크게 점프하며 공중 공격을 두어 번 넣는다

> **보여주는 것**: 이 게임의 정체성. 문장 하나가 판을 바꾼다
> **팁**: 입력을 너무 빨리 치지 말 것. 심사자가 글자를 읽을 시간이 필요하다

### ⑤ 0:34 – 0:44 · 두 번째 오브 — 규칙이 바뀐다 (10초)

- 두 번째 오브를 깨고 이번엔 **룰**을 부른다:

  ```
  리듬으로 승부하자
  ```

- 상단에 박자 게이지가 뜬다
- 박자에 맞춰 때려 **`PERFECT!` 2배** 판정을 최소 한 번 띄운다

> **보여주는 것**: 아이템이 아니라 **승부 규칙 자체**가 바뀐다는 것
> AI가 오브를 깨서 봇이 문장을 외치는 장면이 잡히면 그것도 좋다

### ⑥ 0:44 – 0:51 · 마무리 · 상장폐지 (7초)

- 스킬 `L` — 블루스크린 (지분을 모아 뒀다면 더 좋다)
- 마지막 적을 `K K`로 장외로 날려 **상장폐지** 연출을 띄운다
  → 판이 잠깐 멈추고 `빌 게이츠맨 → OOO 상장폐지!` 가 크게 뜬다

> **보여주는 것**: 스킬 연출 · KO. 누가 누구를 잡았는지가 이름으로 나온다

### ⑦ 0:51 – 0:53 · 결과 화면 (2초)

- 승리 화면을 2초만 유지한다 (뒤에 온라인 구간이 있다)
- 전적표 아래 **“이 판을 바꾼 말”** 세 줄이 한 줄씩 떠오른다 —
  방금 친 `여기를 달로 만들어줘 → 🌙 저중력`, `리듬으로 승부하자 → 🎵 리듬 배틀`이
  그대로 남아 있다. 이 줄이 잡히도록 전적표가 아니라 **화면 아래쪽**에 시선을 둔다

> **보여주는 것**: 판이 끝나도 그 판을 만든 문장이 남는다는 것.
> 앞에서 친 문장과 여기 적힌 문장이 같다는 사실이 영상 안에서 이어진다

### ⑧ 0:53 – 0:58 · **온라인 대전** (5초)

> 이 구간만 미리 준비해 두고 찍는다. 앞과 이어 붙여도 되고 따로 찍어도 된다.

**준비** — 같은 주소를 **창 두 개**로 열어 나란히 놓는다 (탭 아님).
왼쪽 창에서 `F3` → `이 컴퓨터에서 — 방 만들기`,
오른쪽 창에서 `F3` → `이 컴퓨터에서 — 참가`. 붙으면 각자 캐릭터를 고른다.

- 두 창이 같은 판을 보여주는 화면을 **3초** 잡는다
- 오른쪽 창에서 `A`를 눌러 **왼쪽 창의 그 캐릭터도 같이 움직이는 것**을 보여준다

- 여유가 되면 한쪽 창을 **닫아 본다** — 그 자리를 봇이 이어받고 판이 이어진다

> **보여주는 것**: 온라인이 실제로 돈다는 것. 두 화면이 같은 판이라는 사실이
> 한눈에 보여야 하므로, 창을 나란히 놓고 **동시에** 잡는 것이 핵심이다
> **팁**: 인터넷 방(코드 방식)으로 찍어도 되지만, 회선 사정에 기대지 않으려면
> "이 컴퓨터에서" 쪽이 안전하다. 판정되는 것은 같은 코드다

## 2. 반드시 화면에 잡혀야 하는 것 — 체크리스트

찍은 뒤 이 목록으로 확인한다. 하나라도 빠지면 다시 찍는 편이 빠르다.

- [ ] **주가 게이지가 서로 반대로 움직이는 순간** (때린 쪽 ↑ / 맞은 쪽 ↓)
- [ ] **프롬프트 입력창에 한글을 치는 장면** ← 이것이 없으면 의미가 없다
- [ ] **입력한 문장 때문에 화면이 실제로 바뀌는 순간** (배경 교체 · 저중력)
- [ ] **리듬 게이지와 `PERFECT!` 판정**
- [ ] **결과 화면의 “이 판을 바꾼 말”** — 앞에서 친 문장이 그대로 적혀 있는 줄
- [ ] (여유가 되면) **공매도 유령** — 상장폐지된 뒤 떠다니며 물건을 떨어뜨리는 장면
- [ ] **차지 강공격** — 몸을 떨며 모으다 놓는 장면
- [ ] **잡기 → 던지기** — 막고 선 상대를 그대로 잡는 장면
- [ ] 상장폐지(KO) 연출 — `OOO → OOO 상장폐지!` 가 이름으로 나오는 것
- [ ] 캐릭터 선택 화면 (스무 명이 늘어서 있고 각자 다르다는 것)
- [ ] **창 두 개가 같은 판을 보여주는 장면** ← 온라인이 실제로 돈다는 증거

## 4. 자주 어긋나는 것

| 증상 | 대응 |
|---|---|
| 오브가 안 뜬다 | 개시 13초 뒤 첫 등장. 그 전에 죽으면 `R`로 다시 |
| 3AI에게 둘러싸여 금방 죽는다 | 개시 직후 한쪽 끝으로 이동해 1:1 구도를 만든다 |
| 입력창이 너무 빨리 지나간다 | 문장을 다 친 뒤 1초 쉬고 `Enter` |
| 소리가 안 들어갔다 | OBS에서 **브라우저 탭 오디오**가 잡혔는지 확인 |
| 60초를 넘겼다 | ③ 커맨드 무브 구간(6초)을 통째로 뺀다. ④는 절대 줄이지 않는다 |
