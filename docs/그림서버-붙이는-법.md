# 문장이 그림이 되게 하기 (Stable Diffusion 붙이기)

프롬프트 오브를 깨고 문장을 쓰면 판이 바뀐다. 여기에 그림 생성 서버를
붙이면 **그 문장으로 이 판의 배경이 그려진다** — 화면을 한 번 크게 덮었다가
그대로 무대 배경으로 남는다.

붙이지 않아도 게임은 그대로 돌아간다. 주소가 없으면 부르지 않고, 서버가
죽어 있어도 조용히 넘어간다. 그러니 심사자는 아무것도 준비하지 않아도 된다.

---

## 1. 가장 빠른 길 — 로컬 Stable Diffusion WebUI

AUTOMATIC1111(또는 Forge)을 **API와 CORS를 열어서** 띄운다.

```bash
./webui.sh --api --cors-allow-origins=*
# 윈도우: webui-user.bat 의 COMMANDLINE_ARGS 에 --api --cors-allow-origins=* 추가
```

그다음 게임 쪽에 주소만 알려 주면 끝이다. 둘 중 편한 쪽으로 한다.

**(a) 브라우저에서 그 자리에서** — 시연 중에 주소가 바뀌어도 이쪽이면 된다.

```js
// 게임 화면에서 F12 → 콘솔
sdConnect('http://127.0.0.1:7860')
location.reload()
sdStatus()   // { ready: true, mode: 'a1111', ... } 가 나오면 붙은 것이다
```

**(b) 빌드에 넣어서** — 프로젝트 루트에 `.env.local` 을 만든다.

```
VITE_SD_URL=http://127.0.0.1:7860
VITE_SD_MODE=a1111
```

---

## 2. Stability AI (클라우드)

키가 있으면 서버를 띄우지 않아도 된다.

```
VITE_SD_URL=https://api.stability.ai
VITE_SD_KEY=sk-...
VITE_SD_MODE=stability
VITE_SD_ENGINE=stable-diffusion-xl-1024-v1-0
```

> 키가 브라우저에 실린다. 대회 시연처럼 **내 기계에서 내가 켜는** 상황에서만
> 쓰고, 공개 배포에는 아래 3번(중계 서버)을 쓴다.

---

## 3. 직접 만든 중계 서버

키를 감추고 싶거나 다른 모델을 쓰고 싶으면 아무 서버나 하나 세우면 된다.
계약은 이것뿐이다.

```
POST {VITE_SD_URL}
  { prompt, negative_prompt, seed, width, height, steps }
→ { image: "<base64 또는 URL>" }
   또는 { images: ["..."] }  /  { artifacts: [{ base64 }] }
```

```
VITE_SD_URL=https://my-relay.example.com/draw
VITE_SD_MODE=generic
VITE_SD_KEY=...        # 있으면 Authorization: Bearer 로 실린다
```

CORS 헤더(`Access-Control-Allow-Origin`)를 꼭 열어 준다. 브라우저에서
직접 부르기 때문이다.

---

## 설정값 전부

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `VITE_SD_URL` | (없음) | 서버 주소. **비어 있으면 기능 자체가 꺼진다** |
| `VITE_SD_MODE` | `auto` | `a1111` · `stability` · `generic` · `off` · `auto`(주소로 짐작) |
| `VITE_SD_KEY` | (없음) | `Authorization: Bearer` 로 실린다 |
| `VITE_SD_ENGINE` | `stable-diffusion-xl-1024-v1-0` | stability 전용 |
| `VITE_SD_WIDTH` / `VITE_SD_HEIGHT` | `1024` / `576` | 가로로 긴 배경이라 16:9 근처가 좋다 |
| `VITE_SD_STEPS` | `18` | 판이 기다리지 않아야 하므로 낮게 잡았다 |
| `VITE_SD_TIMEOUT` | `25000` | 이 시간 안에 안 오면 포기한다 (ms) |

브라우저에서 넣은 값(`sdConnect`)이 `.env` 보다 세다 — 시연 중에 바꾼 것이
빌드할 때 넣어 둔 것에 지면 안 되기 때문이다.

## 무엇을 보내는가

플레이어가 쓴 한국어 한 줄만 보내면 그림이 잘 안 나온다. 한 줄에는 장면이
부족하고, 모델은 대부분 영어로 배웠다. 그래서 세 조각을 이어 붙여 보낸다.

```
[그림의 결(고정)] + [해석기가 짚은 기믹의 장면 설명(영어)] + [플레이어가 쓴 말]
```

무슨 일이 벌어졌는지는 가운데가 책임지고("용암 지대" → *a volcanic wasteland,
rivers of lava…*), "내가 쓴 그 말"은 뒤가 책임진다. 장면 설명은
`src/config/gimmicks.ts` 의 각 기믹 `art` 필드에 있다.

## 온라인에서는 어떻게 되나

그림을 회선으로 실어 보내지 **않는다**. 문장은 이미 전원에게 가고 씨앗은
문장에서 나오므로, 각자 자기 화면에서 부르면 같은 그림이 나온다. 수백 KB를
데이터 채널에 밀어 넣는 것보다 안전하고, 한 사람이 늦게 받아도 판이
기다리지 않는다.

## 확인

```bash
npm run dev          # 다른 창에서
npm run test:image
```

가짜 SD 서버를 띄워 **실제로 붙여 본다** — 주소가 없을 때 조용한지, 주소를
주면 무엇을 보내는지, 받은 그림이 배경이 되는지, 서버가 죽어도 판이 멀쩡한지.

## 안 나올 때

1. `sdStatus()` — `ready: false` 면 주소가 안 들어간 것이다
2. 콘솔에 CORS 오류 — 서버를 `--cors-allow-origins=*` 로 다시 띄운다
3. 오래 걸린다 — `VITE_SD_STEPS` 를 낮추거나 `VITE_SD_TIMEOUT` 을 늘린다
   (25초가 지나면 포기하고, 게임은 그대로 계속된다)
