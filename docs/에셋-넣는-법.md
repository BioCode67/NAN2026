# 에셋 넣는 법

만든 그림·소리를 **정해진 이름으로 정해진 폴더에 넣기만 하면** 게임이 그것을 씁니다.
코드는 손댈 것이 없습니다. 없는 것은 없는 대로 게임이 완성품으로 돌아갑니다 —
그림이 없으면 도형으로, 소리가 없으면 코드가 만든 곡으로.

---

## 한눈에

| 무엇을 | 어디에 | 이름 |
|---|---|---|
| 캐릭터 그림 | `art-source/` | `<key>_b<묶음>.png` (예: `billgates_b1.png`) |
| 무대 배경 | `public/bg/` | `stage_exchange.png` 등 아래 표 |
| UI 그림 | `public/ui/` | `ui_title_logo.png` 등 아래 표 |
| 곡 | `public/bgm/` | `menu.mp3` · `battle.mp3` · `battle_hot.mp3` |
| 효과음 | `public/sfx/` | `hitLight.mp3` 등 아래 표 |

확장자는 그림 `png`(webp도 됨), 소리 `ogg`·`mp3`·`m4a`·`wav` 아무거나. 먼저 찾은 것을 씁니다.

---

## 1. 캐릭터 그림

**넣는 곳은 `public/` 이 아니라 `art-source/` 입니다.** 받은 그림을 그대로 두면
도구가 배경을 지우고 칸을 잘라 `public/sprites/` 로 옮깁니다.

```
art-source/billgates_b1.png     ← 여기에 그냥 둔다
npm run sheet:merge -- billgates   ← 합친다
npm run art:check                  ← 제대로 붙었는지 본다
```

- 프롬프트는 [`art-source/prompts/복사용/`](../art-source/prompts/복사용/) 에 묶음별 한 장씩 있습니다
  (GitHub 웹에서 열면 코드 블록마다 복사 단추가 붙습니다)
- `<key>` 는 캐릭터마다 정해져 있습니다 — 복사용 문서의 각 프롬프트 위에 적혀 있습니다
- **7칸이 오거나 두 줄로 와도 그대로 넣으면 됩니다.** 도구가 세서 맞춥니다
- 묶음을 다 뽑을 필요 없습니다. **1·3·7·8 네 묶음이면 충분히 볼 만합니다**

## 4. 곡 — `public/bgm/`

| 파일 | 언제 |
|---|---|
| `menu.mp3` | 제목 · 캐릭터 선택 |
| `battle.mp3` | 전투 |
| `battle_hot.mp3` | 전투 — 뜨거운 판 (**선택**) |

`battle_hot` 은 있으면 **마지막 둘이 남거나 서든데스가 걸릴 때 부드럽게 갈아탑니다.**
곡을 끊고 다른 곡을 시작하는 것이 아니라 두 줄을 동시에 틀어 두고 음량만 바꿉니다 —
그래야 "긴장이 올랐다"로 들리지 "노래가 바뀌었다"로 안 들립니다.
같은 길이·같은 BPM 으로 만들어야 하는데, 한 곡의 두 버전이라 원래 그렇게 됩니다.

곡을 하나만 만들어 와도 게임은 완성입니다. `menu` 만 넣으면 전투는 합성 곡이 돕니다.

> 무대마다 곡의 조와 템포가 조금씩 달라집니다 (달 표면은 느리고 낮게).
> 파일 곡에서는 재생 속도로 그렇게 하므로, **루프가 매끄러운 파일**일수록 좋습니다.

## 5. 효과음 — `public/sfx/`

열다섯 개 전부 만들 필요 없습니다. **넣은 것만 파일이 나가고 나머지는 합성입니다.**

| 파일 | 소리 |
|---|---|
| `hitLight.mp3` | 약공격 적중 |
| `hitHeavy.mp3` | 강공격 적중 |
| `hitSkill.mp3` | 스킬 적중 |
| `finisher.mp3` | 마무리 타 |
| `whiff.mp3` | 헛침 |
| `jump.mp3` / `doubleJump.mp3` | 점프 / 2단 점프 |
| `land.mp3` | 착지 |
| `ko.mp3` | 상장폐지 |
| `surge.mp3` | 떡상 |
| `skill.mp3` | 스킬 시전 |
| `gambleWin.mp3` / `gambleLose.mp3` | 도박 성공 / 실패 |
| `uiMove.mp3` / `uiConfirm.mp3` | 메뉴 이동 / 확정 |

세기(연타 수 등)는 **음량으로만** 반영합니다. 녹음된 소리의 피치를 건드리면
다른 소리가 되기 때문입니다 — 만든 사람이 의도한 소리를 그대로 냅니다.

## 제대로 들어갔는지 확인

```bash
npm run art:check      # 그림 — 칸마다 포즈 이름이 붙은 검수 페이지를 만든다
npm run test:audio     # 소리 — 진짜 파일을 넣어 보고 실제로 쓰이는지 확인 (dev 서버 필요)
npm run smoke          # 게임 전체가 처음부터 끝까지 도는지
```

브라우저 콘솔에도 찍힙니다:

```
[Boot] billgates: 42프레임 → V3 규격
[Boot] 소리 파일 — 곡 2개 · 효과음 3개 (나머지는 합성)
```

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 그림을 넣었는데 화면이 그대로 | 낡은 `webp` 가 남아 있다 → `npm run art:check -- --fix` |
| 캐릭터만 동작이 이상하다 | 묶음 칸이 밀렸다 → `art:check` 검수 페이지에서 확인 |
| 곡을 넣었는데 합성 소리가 난다 | 파일 이름·폴더 확인. `npm run test:audio` 가 원인을 말해 준다 |
| 소리가 아예 안 난다 | 브라우저는 첫 클릭·키 입력 전에 소리를 못 냅니다 (정책) |
