# UI 아트

생성한 UI 그림을 여기에 넣는다. 넣으면 다음 새로고침부터 바로 보인다.

| 파일 | 쓰이는 곳 | 형식 |
|---|---|---|
| `ui_title_logo.png` | 타이틀 화면 로고 | 투명 배경 |
| `ui_title_bg.png` | 타이틀 화면 배경 | 16:9 |
| `ui_select_bg.png` | 캐릭터 선택 화면 배경 | 16:9 |
| `ui_result_bg.png` | 승패 결과 화면 배경 | 16:9 |
| `ui_item_icons.png` | 떨어지는 아이템 아이콘 | 가로 6칸 띠, 투명 배경 |
| `ui_prompt_orb.png` | 프롬프트 오브 (온전→금→직전→파괴) | 가로 4칸 띠, 투명 배경 |

프롬프트는 `art-source/prompts/scenes/` 에 있다 (`npm run prompts` 로 다시 만든다).

- 띠 그림은 게임이 가로로 **똑같이 나눠** 쓴다. 해상도는 상관없다
- 투명이 안 돼서 마젠타(#FF00FF) 배경으로 왔으면 게임이 자동으로 지운다
- 없는 파일은 코드로 그린 화면·이모지로 대체된다
